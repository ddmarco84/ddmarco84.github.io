\section{Applied Data Science Projects}
\textbf{Loan Default Prediction (MIT Capstone)} | \cvlink{https://github.com/ddmarco84/project}{GitHub} \hfill Oct 2025
\begin{itemize}[noitemsep, topsep=2pt]
    \item Built a credit-risk decision prototype for HMEQ home-equity loans, comparing six classifiers to identify borrowers with elevated default risk.
    \item Selected XGBoost as the strongest held-out model (ROC-AUC 0.964; default recall 0.832; F1 0.814), then optimised the lending threshold to minimise expected losses.
    \item Used SHAP to translate predictions into explainable risk drivers: debt burden, credit history, loan size, and property variables.
\end{itemize}

\noindent\textbf{Predicting Potential Customers (MIT Elective)} | \cvlink{https://www.mygreatlearning.com/eportfolio/marco-pelliccia}{Portfolio} \hfill Oct 2025
\begin{itemize}[noitemsep, topsep=2pt]
    \item Built a lead-prioritisation pipeline for 4,612 ExtraaLearn leads, selecting the contact threshold on validation data before final test evaluation.
    \item Delivered an operational lead-scoring file with predicted conversion probabilities, priority bands, and recommended outreach actions.
    \item On the test set, achieved ROC-AUC 0.926 and average precision 0.839; the top 10\% of scored leads converted at 91.4\%, about 3.1x the base rate.
\end{itemize}
